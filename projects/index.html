AI for Security

Malware Image Classifier (ResNet50)

Classifies Windows malware into 25 families by treating each executable as a grayscale image. An ImageNet-trained ResNet50 is fine-tuned on the Malimg dataset with a frozen backbone and a new classification head, using an 80/20 train/test split. After 10 epochs it reaches 95.2% training accuracy and 88.1% on the held-out test set.
